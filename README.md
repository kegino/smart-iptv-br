# Smart IPTV BR (smartiptvbr.site)

Site oficial do **Smart IPTV BR** - O melhor serviço de canais ao vivo, filmes e séries para Smart TV Samsung, LG e Android com servidores dedicados no Brasil e 0% de travamento.

## 🚀 Tecnologias

- **Framework**: TanStack Start / React 19 / Vite
- **Estilização**: Tailwind CSS com tema *Aviation Cyan* inspirado em *Top Gun: Maverick*
- **SEO**: Meta tags completas, OpenGraph, Twitter Cards, Schema.org (Organization, WebSite, FAQPage, Article), Sitemap XML, RSS Feed e Robots.txt
- **Imagens**: Fundo Hero em formato WebP ultra-otimizado e centralizado para telas mobile.
- **Botões**: Alto contraste com texto legível, sombras ciano vibrantes e visibilidade total.

## 📦 Scripts

- `pnpm dev`: Inicia o servidor de desenvolvimento local
- `pnpm build`: Compila e gera a versão de produção otimizada
- `pnpm start`: Inicia o servidor de produção
